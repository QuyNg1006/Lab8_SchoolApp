# School App Projects

## Exercise 1: Razor Pages Application
- Description: ASP.NET Core Razor Pages project using Code First approach.
- Folder: `Exercise1_RazorPages/SchoolAppCoreRazor`
- Instructions: Open in Visual Studio, run `Add-Migration InitialCreate` and `Update-Database` in Package Manager Console, then press F5 to run.

## Exercise 2: MVC Application
- Description: ASP.NET Core MVC project using Code First approach.
- Folder: `Exercise2_MVC/SchoolAppCoreMVC`
- Instructions: Open in Visual Studio, run `Add-Migration InitialCreate` and `Update-Database` in Package Manager Console, then press F5 to run.

## Database
- Connection string is in `appsettings.json` (`SchoolDBConnectionString`, default `(local)\SQLEXPRESS`).
- A ready SQL script is in `SQL/` (SchoolDB.sql, SchoolDBMVC.sql).
